# run-router-api

## Product Overview
Route Runner is an AI-powered running route generator that converts natural language descriptions into real-world running routes with turn-by-turn geometry, elevation data, and GPX export. A user says "5 mile loop around Green Lake" and gets back a mapped route that follows actual roads, trails, and paths — complete with distance, elevation gain, estimated duration, and a downloadable GPX file for their GPS watch.
